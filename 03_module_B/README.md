# ChileVenture — Tourism Landing Page

A tourism landing page for **ChileVenture**, a fictional Chilean adventure travel company, developed as part of the **WorldSkills Americas 2025 Web Technologies** competition.

The project focuses on reproducing a provided visual design with a strong emphasis on **visual fidelity, semantic HTML, CSS organization, accessibility, and interactive CSS effects**.

## 🌎 Live Demo

[View Live Project](https://world-skills-americas-modules.vercel.app/)

## 📖 About the Project

ChileVenture is a tourism website designed to showcase Chilean destinations, travel packages, adventure activities, special offers, and traveler experiences.

The objective of the competition task was to transform a provided design reference into a functional desktop landing page while following strict technical requirements.

The website includes:

* Navigation menu with dropdown submenus
* Hero section with travel search form
* Popular destinations
* Popular travel packages
* Adventure & activities
* Special travel offers
* Traveler gallery
* Newsletter subscription
* Footer with contact and legal information

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **Font Awesome** for icons

### Restrictions

The project was developed under the following competition constraints:

* No JavaScript
* No CSS frameworks
* No external libraries
* Desktop layout only (`≥ 1280px`)
* Semantic HTML5 structure
* Accessible images with alternative text
* Accessible form labels
* Visual contrast considerations
* CSS-only interactive effects

## ✨ Features

### Responsive & Structured Layout

The page is organized into independent semantic sections using elements such as:

```html
<header>
<nav>
<main>
<section>
<footer>
```

### CSS Navigation

The navigation includes dropdown menus and a CSS-only hamburger interaction without JavaScript.

### Hover Effects

Interactive elements include:

* Button color transitions
* Navigation hover states
* Dropdown menus
* Activity card movement on the Y-axis
* Box-shadow effects on activity cards

### Travel Search

The hero section includes a travel search interface with:

* Destination
* Number of people
* Check-in date
* Check-out date
* Search button

## 🎯 Competition Objective

The project was developed following the **WorldSkills Americas 2025 Web Technologies** layout task requirements.

The main objective was to achieve high visual fidelity to the provided reference design while maintaining clean HTML5 and CSS3 implementation.

Particular attention was given to:

* Typography
* Colors
* Spacing and margins
* Layout structure
* Visual hierarchy
* Component positioning
* Hover interactions
* Accessibility
* Code organization
